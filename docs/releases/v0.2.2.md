# Hangfire.RecurringJobs v0.2.2

## Fixes

- The library assembly no longer contains a public `Program` type or an entry point. Hosts that use top-level statements with `WebApplicationFactory<Program>` no longer fail with `CS0433: The type 'Program' exists in both ...`.
- The package is now built as a Razor class library (`Microsoft.NET.Sdk.Razor` with a framework reference to `Microsoft.AspNetCore.App`) and no longer ships a `runtimeconfig.json`. The public API, routes, pages, and static assets are unchanged.
